## Key Conceptual Clarifications

1. **tseq = last_day**: The maximum day in the timeline for a timing_sequence block
2. **Block-level computation**: Compute once per timing_sequence, not per drug or per row
3. **Purpose**: Ensure all drugs in the same block can be stacked into a matrix with uniform vector length
4. **Edge case**: Drugs with mismatched allDays (e.g., [1,2,3] vs [10,11]) or cycle lengths need uniform padding

## Code Intent is Now Clear

- Computing tseq once per timing_sequence block
- Applying that tseq uniformly to all drugs in the block
- Creating variants (lb/ub splits) with same tseq
